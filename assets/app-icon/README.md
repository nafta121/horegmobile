# HOREGDAW app icon

The official **HOREGDAW** mobile app icon: a rounded square badge with a mint-sage border (`#96bcb7`) on a dark slate-teal field (`#212b2d`), featuring the geometric **H** emblem with angled lower legs, six symmetric beveled soundwave bars, and the bold **HOREGDAW** wordmark below.
